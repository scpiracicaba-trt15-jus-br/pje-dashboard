Sobre os dados
  • Fonte: relatório "IGest – 1º Grau" da CGJT, período de referência de 01/10/2025 a 30/09/2026, atualizado em 03/11/2026. Dados extraídos do e-Gestão.
  • IGEST = 0,2 × (Acervo + Celeridade + Produtividade + Congestionamento + Força de Trabalho). Cada mesoindicador é a média ponderada dos microindicadores padronizados de 0 a 1 pelo boxplot da faixa de casos novos da vara. 0 é o melhor valor e 1 o pior.
  • Faixas: quartis nacionais (1ª = 25% melhores varas do país; 4ª = 25% piores). Foram usadas as faixas publicadas no relatório.
  • O índice de cada Secretaria Conjunta é a média simples do índice das suas varas. A CGJT não calcula IGEST por Secretaria Conjunta: é uma consolidação feita para este painel.
  • Na tabela de índices brutos, a idade média do pendente de julgamento e os prazos médios das SCs são médias simples das varas, porque o relatório não traz os pesos necessários para a média ponderada.
