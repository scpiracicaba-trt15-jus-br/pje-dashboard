🤖 Como usar o script multi-vara

1
Abra o terminal: Windows + R → cmd → Enter
2
Navegue: cd Desktop\PJE-Dashboard
3
Rode: python pje_coletor.py
4
Faça login, vá ao painel e pressione Enter
5
Aguarde — o script percorre todas as 10 varas automaticamente (~40-60 min)
6
Carregue o JSON aqui e veja todos os dados
